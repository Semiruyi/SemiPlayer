# SemiPlayer portable example

Open `bin/semi_player_sdl.exe` to play the bundled sample immediately.
To play another media file, drag it onto the executable or pass its path from
a terminal:

```text
bin\semi_player_sdl.exe path\to\media.mp4
```

Controls:

- Space: play or pause
- Left/Right: seek five seconds backward or forward
- F11: toggle fullscreen
- Escape: quit

This preview package contains SemiPlayer, SDL3, FFmpeg, and their runtime
dependencies. It does not require MSYS2 to be installed on the target machine.
